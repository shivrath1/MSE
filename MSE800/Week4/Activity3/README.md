# Use Case Diagrams — Money Exchange App
 
## Use Case Diagram 1 — Customer Interactions
 
This diagram shows what a customer can do in the money exchange system. The primary actor is the Customer, who can register, verify their identity (KYC), manage their account, view exchange rates, initiate a currency exchange, and view their transaction history. When a customer initiates an exchange, the system calculates the exchange amount and applies the fee these are mandatory steps that always happen together with the transaction.
 
## Use Case Diagram 2 — Admin Management
 
This diagram shows how the admin manages and controls the money exchange system. The primary actor is the Admin, who can approve or reject customers, freeze accounts, set exchange rates, configure fee rules, manage the currency list, monitor transactions, reverse a transaction and generate reports.
