# Off Diagonal Elements 
Off diagonal elements measure how "quantum" the qubit still is when they disappear, the qubit has lost its superposition and behaves classically.

## Example
Diagonal Elements :
[ 0.5   -  ]
[  -   0.5 ]

Top-left 0.5 = probability of measuring |0⟩
Bottom-right 0.5 = probability of measuring |1⟩
Always real numbers, always add up to 1


Off Diagonal Elements:
[  -   0.5 ]
[ 0.5   -  ]
These represent quantum coherence:
How much the qubit is "aware" of both states simultaneously
